## What I'm Building

I build software around **AI, automation, developer tools, and systems that solve problems I actually have.**

Most of my projects start as experiments. The ones that survive become products, tools, or open-source projects.

### Kabaadiwala Connect

A technology platform exploring how AI can help informal waste collectors identify, sort, and connect recyclable materials with the right buyers.

`AI` `Computer Vision` `Web` `Sustainability`

**Focus:**
